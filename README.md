# Описание приложений

Приложения представляют собой канбан-доску в четырёх реализациях с разными стейт-менеджерами (Jotai, MobX, Zustand, Tanstack). Колонки, карточки и журнал приходят с сервера. Черновик, выбор карточки, свёрнутые колонки и перетаскивание остаются в браузере.

На экране три колонки: Backlog, Doing и Done. Карточку можно выбрать, открыть на отдельной странице, перетащить в другую колонку или добавить из черновика. Фильтры оставляют карточки по тексту, исполнителю и метке. Действия пользователя на странице записываются в журнал действий.

| Приложение | Порт | Серверный снимок | Клиентское состояние |
| --- | --- | --- | --- |
| [Jotai](apps/jotai) | 3001 | `useHydrateAtoms`, один раз на store | атомы, `atomFamily`, `unwrap` |
| [MobX](apps/mobx) | 3002 | `hydrate()`, повторный вызов игнорируется | observable, `computed`, `flow` |
| [Zustand](apps/zustand) | 3003 | vanilla store, созданный в `useState` | слайсы и middleware |
| [TanStack](apps/tanstack) | 3004 | `dehydrate` и `HydrationBoundary` | TanStack Store |


# Структура

Монорепозиторий pnpm. В корне `package.json` и `pnpm-workspace.yaml`. Четыре приложения лежат в `apps`, общий пакет — в `packages/board-kit`. Сторов в общем пакете нет: каждое приложение само держит снимок и клиентское состояние.

```text
apps/jotai, apps/mobx, apps/zustand, apps/tanstack
  src/app                страницы доски и карточки, маршруты API
  src/state              состояние выбранной библиотеки
  src/components         экраны, которые связывают это состояние с общим UI
packages/board-kit/src
  types.ts, view.ts      типы снимка и модели для экрана
  board.ts               сборка колонок и локальный перенос карточки
  client                 запросы к API
  server                 серверная часть
  components             колонки, карточки, фильтры, журнал, полоска снимка
  helpers                сравнения, события перетаскивания, счётчик рендеров
```

# Запуск

```bash
pnpm install
pnpm dev
```

Приложения доступны на `localhost:3001`–`localhost:3004`.
